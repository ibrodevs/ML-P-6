## Цель работы

Реализовать полный базовый NLP-пайплайн: очистить текст, выполнить токенизацию и стемминг, преобразовать документы в TF-IDF-признаки, обучить классификатор и содержательно разобрать ошибки модели.

## Что реализовано

- перевод текста в нижний регистр;
- удаление пунктуации, цифр и стоп-слов;
- токенизация регулярным выражением;
- Snowball stemming для русского и английского;
- `TfidfVectorizer` с `min_df`, `max_df` и биграммами;
- `LogisticRegression`;
- train/test split до обучения TF-IDF, чтобы исключить leakage;
- сохранение метрик и анализ 5 ошибок модели.

## Данные

`data.csv` содержит **175** коротких отзывов двух классов: `positive` и `negative`.

## Ключевые результаты

```text
Train: 122
Test: 53
TF-IDF признаков: 115
Accuracy: 0.8679
Macro F1: 0.8679
```

Одна из важных найденных проблем: удаление слова `не` как стоп-слова может инвертировать смысл, например `не хороший` превращается фактически в `хороший`.

## Запуск

```bash
pip install -r requirements.txt
python text_classification.py
```

## Ключевой вывод

TF-IDF хорошо работает как простой baseline для текстовой классификации, но не понимает полный контекст и отрицания. Поэтому ошибки особенно часто возникают в текстах со смешанной тональностью, отрицаниями и зависимостью смысла от порядка слов.
